# 「朝夕」官网部署指南（宝塔 · 单域名方案）

> **目标结构**：`zhaoxi.btrencai.top` 一个域名、一个站点，同时提供：
>
> | 路径 | 去向 |
> |---|---|
> | `https://zhaoxi.btrencai.top/` | 官网首页（静态文件） |
> | `https://zhaoxi.btrencai.top/api/*` | 云同步 API（反代 127.0.0.1:8787，客户端用） |
>
> 原理：宝塔中一个域名只能绑定一个站点 → 只留 **HTML项目**，把 `/api/` 反向代理加进它。

## 第 1 步 · 删除旧的反向代理项目

宝塔 → **网站 → 反向代理** → 找到 `zhaoxi.btrencai.top` → **删除**。

> 说明：它只是一个"转发壳"；云同步服务本体是独立的 Python 项目（监听 8787），不受影响。
> 删除到重新配好期间，公网访问会短暂中断（1~5 分钟），客户端稍后自动恢复。

## 第 2 步 · 确认 HTML项目

宝塔 → **网站 → HTML项目** → `zhaoxi.btrencai.top` → 设置 → **域名管理**：
确认有一条 `zhaoxi.btrencai.top`（若显示"不可操作"，先删除该条、再重新添加一次）。

## 第 3 步 · 上传官网文件

**文件** → 进入该项目的网站目录（设置 → 网站目录 里可见，通常为 `/www/wwwroot/zhaoxi.btrencai.top`）→ 上传 `官网部署包.zip` → **解压**（`index.html` 与 `assets/` 直接位于该目录）。

> 权限异常：`chown -R www:www /www/wwwroot/zhaoxi.btrencai.top`

## 第 4 步 · 给 HTML项目加 /api/ 反向代理

HTML项目 → 设置 → **反向代理** → 添加反向代理：

- 代理目录：`/api/`
- 目标 URL：`http://127.0.0.1:8787`（**结尾不要加斜杠**）
- 其余默认 → 提交

> 如果设置里没有"反向代理"入口，改用：设置 → **配置文件**，在 `server { }` 内加：
>
> ```nginx
> location ^~ /api/ {
>     proxy_pass http://127.0.0.1:8787;
>     proxy_set_header Host $host;
>     proxy_set_header X-Real-IP $remote_addr;
>     proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
>     proxy_set_header X-Forwarded-Proto $scheme;
> }
> ```

## 第 5 步 · SSL

HTML项目 → 设置 → **SSL** → Let's Encrypt → 申请（勾选自动续签）→ 打开「强制 HTTPS」。

## 验证

```bash
curl -I https://zhaoxi.btrencai.top/          # 官网：200 + HTML
curl -s https://zhaoxi.btrencai.top/api/health # API：200
```

浏览器打开官网、桌面客户端登录/同步 —— 都应正常。

## 常见问题

| 现象 | 解决 |
|---|---|
| 首页 403 | `chown -R www:www /www/wwwroot/zhaoxi.btrencai.top` |
| 首页 404/目录列表 | 官网文件没放进该站点根目录 |
| /api/ 404 或 502 | 反代规则未生效：确认代理目录为 `/api/`、目标无结尾斜杠；重载 Nginx |
| 客户端登录失败 | `/api/` 反代被改坏：按第 4 步重新核对 |
| 页面旧版 | Ctrl+F5 强制刷新 |

## 后续更新官网

改完 `website/` 后重新上传覆盖根目录即可（静态文件无需重启服务）。
