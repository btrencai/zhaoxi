# 「朝夕」官网部署指南（宝塔面板）

> 官网是**纯静态页面**（`website/` 目录：index.html + assets/），部署后：
> - `https://zhaoxi.btrencai.top/` → 官网首页
> - `https://zhaoxi.btrencai.top/api/*` → 云同步 API（保持原来的 8787 反代，**客户端不受任何影响**）

## 第 1 步 · 上传文件

宝塔面板 → **文件** → 进入 `/www/wwwroot/` → 新建目录 `zhaoxi-site`

把部署包里的 `index.html` 和 `assets/` 整个目录上传进去（或用「上传」传 `官网部署包.zip` 后右键**解压**到该目录）。

上传后最终结构应为：

```
/www/wwwroot/zhaoxi-site/
├── index.html
└── assets/
    ├── icon.png
    ├── shot-todos-light.png
    ├── shot-todos-dark.png
    ├── shot-focus.png
    ├── shot-stats.png
    ├── shot-settings.png
    └── shot-notes.png
```

> 权限：目录 755、文件 644；如果宝塔提示权限问题，执行
> `chown -R www:www /www/wwwroot/zhaoxi-site`

## 第 2 步 · 设置网站根目录

宝塔 → **网站** → 点 `zhaoxi.btrencai.top` 的「设置」→ **网站目录** → 把网站目录改为 `/www/wwwroot/zhaoxi-site` → 保存。

## 第 3 步 · 修改站点配置（静态 + API 共存）

还是在「设置」里 → **配置文件**。找到原来的反向代理配置（类似下面这段），并替换：

**原来（大概长这样，替换掉）：**

```nginx
location / {
    proxy_pass http://127.0.0.1:8787;
    proxy_set_header Host $host;
    ...
}
```

**替换为（以下四段）：**

```nginx
    # 官网静态目录
    root /www/wwwroot/zhaoxi-site;
    index index.html;

    # API 反代（保持端口 8787 不变）
    location /api/ {
        proxy_pass http://127.0.0.1:8787;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 静态文件与首页
    location / {
        try_files $uri $uri/ /index.html;
    }
```

> ⚠️ 只动 `location` 相关部分；`listen` / `ssl_certificate` / `server_name` / 日志等行**保持原样**。
> 保存后宝塔会自动校验语法，没问题就点「重载配置」（或服务 → Nginx → 重载）。

## 第 4 步 · 验证

```bash
# 1) 官网首页应返回 200 且带 HTML
curl -I https://zhaoxi.btrencai.top/

# 2) API 健康检查应仍返回 200（客户端依赖它）
curl -s https://zhaoxi.btrencai.top/api/health
```

浏览器打开 `https://zhaoxi.btrencai.top` → 应看到官网首页；打开桌面客户端 → 登录/同步一切照旧。

## 常见问题

| 现象 | 原因与解决 |
|---|---|
| 首页 403 | 目录权限问题：`chown -R www:www /www/wwwroot/zhaoxi-site`，确认目录里有 index.html |
| 首页 404 / 显示目录列表 | 网站目录没改到 `zhaoxi-site`，或 root 路径写错 |
| API 404/502 | `location /api/` 的反代段没生效：检查缩进与分号、点「重载配置」 |
| 改了配置客户端登录失败 | 说明 /api/ 反代被改坏：回到配置文件核对上面那段，或恢复原配置后重试 |
| 浏览器缓存旧页面 | 强制刷新（Ctrl+F5）；首次部署一般无此问题 |

## 后续更新官网

改完 `website/` 里的文件后，重新上传覆盖 `/www/wwwroot/zhaoxi-site/` 即可（静态文件无需重启任何服务）。
