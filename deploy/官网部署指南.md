# 「朝夕」官网部署指南（宝塔 · HTML项目 + www 子域名）

> **最终结构**（两个项目各司其职，互不影响）：
>
> | 域名 | 项目类型 | 用途 |
> |---|---|---|
> | `www.zhaoxi.btrencai.top` | **HTML项目**（新建，纯静态） | 产品官网 |
> | `zhaoxi.btrencai.top` | 反向代理项目（**保持原样不动**） | 云同步 API（客户端使用） |

## 第 1 步 · 域名解析

在域名服务商（阿里云 DNS 等）为 `btrencai.top` 添加记录：

```
记录类型：A    主机记录：www    记录值：1.117.75.189
```

## 第 2 步 · 新建 HTML项目

宝塔 → **网站 → HTML项目 → 添加项目**：

- 域名：`www.zhaoxi.btrencai.top`
- 根目录：默认（`/www/wwwroot/www.zhaoxi.btrencai.top`）
- 其余默认 → 提交

## 第 3 步 · 上传官网文件

宝塔 → **文件** → 进入上面的根目录 → 上传 `官网部署包.zip` → 右键**解压**（解压后 `index.html` 与 `assets/` 直接位于该目录）。

> 权限异常时执行：`chown -R www:www /www/wwwroot/www.zhaoxi.btrencai.top`

## 第 4 步 · HTTPS

网站 → `www.zhaoxi.btrencai.top` → 设置 → **SSL** → Let's Encrypt → 申请（勾选自动续签）→ 打开「强制 HTTPS」。

## 验证

```bash
# 官网（应 200 且返回 HTML）
curl -I https://www.zhaoxi.btrencai.top/

# API（客户端依赖，保持原样即应 200）
curl -s https://zhaoxi.btrencai.top/api/health
```

## 可选 · 让裸域名访问时跳到官网

访问 `https://zhaoxi.btrencai.top`（无 www）时目前会打到 API 根路径（返回 JSON 404）。
想让它自动跳转到官网，在**反向代理项目**的「配置文件」里加一行（只影响根路径，`/api/*` 不受影响）：

```nginx
location = / {
    return 301 https://www.zhaoxi.btrencai.top;
}
```

保存后宝塔会自动重载。**不加也完全没问题** —— 裸域名本来只给客户端用。

## 常见问题

| 现象 | 解决 |
|---|---|
| 首页 403 | `chown -R www:www /www/wwwroot/www.zhaoxi.btrencai.top` |
| 域名打不开 / 证书报错 | 检查 www 的 A 记录是否生效（`ping www.zhaoxi.btrencai.top`）；SSL 是否申请成功 |
| 客户端登录失败 | 说明动到了 `zhaoxi.btrencai.top` 的反代规则：将其恢复为「代理目录 `/` → `http://127.0.0.1:8787`」即可 |
| 页面是旧版 | Ctrl+F5 强制刷新 |

## 后续更新官网

改完 `website/` 里的文件后，重新上传覆盖根目录即可（静态文件无需重启服务）。
