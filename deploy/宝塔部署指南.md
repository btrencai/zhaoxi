# 朝夕 · 宝塔面板部署指南

> 面向：已装宝塔 Linux 面板的服务器（如腾讯云轻量/云服务器）。
> 目标：把 `cloud-server.py`（整个后端，单文件、零依赖）跑起来，并用 HTTPS 域名对外服务。

## 一、准备工作（3 分钟）

1. **上传文件**：面板左侧「文件」→ 进入 `/www/wwwroot/` → 新建目录 `zhaoxi-cloud`
   → 进入该目录 → 上传 `cloud-server.py`。
2. **目录权限**：面板「终端」（或 SSH）执行：

   ```bash
   chown -R www:www /www/wwwroot/zhaoxi-cloud
   ```

3. （可选）本机先验证能跑：

   ```bash
   cd /www/wwwroot/zhaoxi-cloud && python3 cloud-server.py --port 8787 --db ./zhaoxi-cloud.db
   # 看到「朝夕云同步服务器已启动」即成功，Ctrl+C 退出
   ```

## 二、添加 Python 项目（照着截图里那个弹窗填）

| 字段 | 填写内容 |
|---|---|
| 项目名称 | `zhaoxi-cloud` |
| Python 环境 | 选你已装的（如 Python 3.12.3，3.8+ 均可） |
| 启动方式 | **命令行启动** |
| 项目路径 | `/www/wwwroot/zhaoxi-cloud` |
| 启动命令 | `python cloud-server.py --host 127.0.0.1 --port 8787 --db /www/wwwroot/zhaoxi-cloud/zhaoxi-cloud.db` |
| 环境变量 | 无 |
| 启动用户 | `www` |
| 安装依赖包 | **留空**（本项目零第三方依赖，无需 requirements.txt） |

点「确定」→ 面板会自动建虚拟环境并启动；在列表里能看到运行状态与日志。

> 说明：`--host 127.0.0.1` 表示只监听本机，由第三步的反向代理对外服务（更安全）。
> 若暂不做域名，想先用 `http://IP:8787` 直连：把 `--host` 改成 `0.0.0.0`，
> 并在「安全」放行 8787（云厂商控制台的**安全组**也要放行，见第五节）。


## 二·五、配置邮件服务（注册邮箱验证码 · 必须）

注册已升级为**邮箱验证码**（防止随便注册），因此服务器**必须配置 SMTP** 才能注册。
在 `/www/wwwroot/zhaoxi-cloud/` 下新建 `cloud-config.json`：

```json
{
  "smtp_host": "smtp.qq.com",
  "smtp_port": 465,
  "smtp_tls": "ssl",
  "smtp_user": "你的QQ邮箱@qq.com",
  "smtp_pass": "SMTP授权码",
  "smtp_from": "你的QQ邮箱@qq.com"
}
```

- **QQ 邮箱授权码怎么拿**：登录 QQ 邮箱网页版 → 设置 → 账户 →
  开启「POP3/IMAP/SMTP 服务」→ 生成授权码（16 位，**不是 QQ 密码**）。
- 其他邮箱同理（163：smtp.163.com:465 / ssl；企业邮按服务商文档填）。
- `smtp_from` 必须与发件账号一致，否则会被邮箱服务商拒绝。
- 然后在面板里**重启 zhaoxi-cloud 项目**，注册测试一次：应能收到「【朝夕】注册验证码」邮件。

> 排错：注册返回「服务器未配置邮件服务」= cloud-config.json 没建或没重启；
> 返回「邮件发送失败：...」= 授权码/端口/TLS 模式不对，按报错原文核对。

## 二·六、更新服务端（收到新版 cloud-server.py 时）

覆盖上传 `cloud-server.py` → 面板重启项目即可，数据库与账号不受影响。

## 三、域名 + HTTPS 反向代理（推荐）

1. **解析域名**：在域名商处把 `todo.example.com` 的 A 记录指向你的服务器 IP。
2. **建站点**：「网站」→ 添加站点 → 域名 `todo.example.com`，PHP 版本纯静态即可。
3. **反向代理**：站点设置 → 反向代理 → 添加：
   - 代理名称：`zhaoxi-api`
   - 目标 URL：`http://127.0.0.1:8787`
   - 发送域名：`$host`
4. **申请 SSL**：站点设置 → SSL → Let's Encrypt 一键申请 → 开启「强制 HTTPS」。
5. **验证**：浏览器打开 `https://todo.example.com/api/health`
   → 应返回 `{"ok": true, "name": "zhaoxi-cloud", ...}`。

## 四、在客户端里使用

打开「朝夕」→ 登录页：
- **服务器地址**：`https://todo.example.com`（或直连方案：`http://1.117.75.189:8787`）
- 点「注册」填写邮箱密码 → 注册成功即完成首次同步。

> 之后把该地址发我，可以给你构建「内置官方服务器」版本：用户无需手动填地址。

## 五、防火墙两处都要开（最常见的坑）

| 位置 | 操作 |
|---|---|
| 宝塔面板「安全」 | 放行 `80`、`443`（直连方案另加 `8787`） |
| 云厂商控制台（如腾讯云）→ 轻量应用服务器/云服务器 → **防火墙/安全组** | 同样放行上述端口 |

只开一处 = 浏览器访问不了，务必两处都检查。

## 六、数据备份（面板「计划任务」，每天一次）

- 任务类型：Shell 脚本；执行周期：每天 3:30
- 脚本内容：

```bash
mkdir -p /www/wwwroot/zhaoxi-cloud/backup
cp /www/wwwroot/zhaoxi-cloud/zhaoxi-cloud.db /www/wwwroot/zhaoxi-cloud/backup/zhaoxi-$(date +\%F).db
find /www/wwwroot/zhaoxi-cloud/backup -name "*.db" -mtime +30 -delete
```

（备份 + 只保留最近 30 天。数据库就是这一个文件，复制即备份。）

## 七、排错速查

| 现象 | 处理 |
|---|---|
| 项目启动失败 | 看项目日志；确认启动命令里 `python` 可用（面板虚拟环境自带）；确认目录属主是 `www` |
| 面板里显示运行中，但外部访问超时 | 99% 是第五节两处防火墙没开齐 |
| `https://域名/api/health` 502 | 反向代理目标写错（应为 `http://127.0.0.1:8787`），或 Python 项目没在运行 |
| 注册返回 429 | 触发了限流（认证接口 60 次/分钟/IP），等一分钟即可 |
| 想换端口/数据库位置 | 改启动命令里的 `--port` / `--db` 两个参数，重启项目 |

## 八、升级与迁移

- **升级**：覆盖上传新的 `cloud-server.py` → 面板里重启该项目即可（数据库文件不受影响）。
- **迁移**：把 `cloud-server.py` + `zhaoxi-cloud.db` 两个文件拷到新机器，重复第二节即可。
